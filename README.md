# Brave Debloat

This project aims to debloat Brave Browser and provide a Brave Origin-like experience without having to manually check and toggle settings.

## Features Disabled

Brave Origin reference: [What is Brave Origin?](https://support.brave.app/hc/en-us/articles/38561489788173-What-is-Brave-Origin)

- Leo
- News
- Playlist
- Rewards
- Speedreader
- Stats, crash logs, and privacy-preserving product analytics (P3A)
- Talk
- Tor
- VPN
- Wallet
- Wayback Machine
- Web Discovery Project
